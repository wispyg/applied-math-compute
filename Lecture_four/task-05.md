### А. Формула для SymPy — 4 хвилини

Виконайте клітинку, спочатку на навчальній формулі:

```python
import sympy as sp

x = sp.symbols('x')
formula = x**2 - 1 - sp.cos(x)

def check_again(start=1.0):
    try:
        root = sp.nsolve(formula, x, start)
        print("Кандидат nsolve:", root)
        print("Нев'язка:", abs(formula.subs(x, root).evalf()))
    except (ValueError, ZeroDivisionError) as error:
        print("Пошук не завершився:", error)

interact(check_again, start=FloatText(value=1.0, description="Старт"))
```

`SymPy` зберігає формулу із символом `x`, а `nsolve` чисельно шукає один корінь зі старту. `subs(x, root)` підставляє кандидата у формулу, `evalf()` обчислює числове значення. `try/except` у готовій заготовці лише показує повідомлення, якщо пошук не вдався; самостійно цей службовий блок писати не потрібно. Введіть `-1` та `1` і порівняйте результати.
