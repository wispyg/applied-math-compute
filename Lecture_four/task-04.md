### А. Готовий експеримент — 4 хвилини

Скопіюйте й запустіть код; писати інтерфейс самостійно не потрібно.

```python
def f(x):
    return x**2 - 1 - np.cos(x)

def check(start=1.0):
    roots, details, status, message = fsolve(f, start, full_output=True)
    root = float(roots[0])
    print("Кандидат:", root)
    print("Нев'язка:", abs(float(f(root))))
    print("Успішне завершення:", status == 1)
    print(message)

interact(check, start=FloatText(value=1.0, description="Старт"))
```

`NumPy` тут надає числовий косинус, а `fsolve` багато разів обчислює `f`, уточнюючи наближення; усі ітерації бібліотека робить усередині. `full_output=True` додає діагностику, `status == 1` означає повідомлення розв'язувача про успіх. `FloatText` створює поле: після зміни числа й підтвердження введення `check` запускається знову. Нев'язка — модуль різниці частин рівняння.
