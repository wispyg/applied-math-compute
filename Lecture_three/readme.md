# Практичне заняття №3: юніт-тести у Python

Перевіряємо зміну яскравості одного пікселя: від контракту й першого `assert` до граничних випадків і виявлення навмисних дефектів.

**Лекційне пояснення: 40 хвилин.** Чотири вправи за прикладами лекції наведено нижче.

## Самостійна робота

1. [Python Koans — 10 хвилин](task-01.md): виправлення невдалих перевірок; здати скріншот із кількістю пройдених тестів.
2. [cyber-dojo — 10 хвилин](task-02.md): Fizz Buzz і власні тести; здати скріншот із кількістю пройдених тестів.
3. [Тести для свого варіанта лабораторної 1, завдання 1.1](task-03.md): перевірити обчислення та очікувану помилку ділення на нуль.

Повні умови й вимоги до здачі містяться в окремих файлах завдань.

## Запуск у браузері

[Відкрити notebook у Google Colab](https://colab.research.google.com/github/mitikov/applied-math-compute/blob/main/Lecture_three/unit_tests.ipynb).

Notebook сам створює потрібні файли в окремому тимчасовому каталозі, тому клонувати репозиторій не потрібно; для редагування збережіть власну копію notebook і виконуйте комірки зверху вниз.

## Локальний запуск

Потрібен Python 3.10 або новіший. Завантажте каталог або клонуйте репозиторій, відкрийте термінал у `Lecture_three` та виконайте:

```bash
python -m pip install -r requirements.txt
python -m pytest -q
```

Початковий готовий набір містить **8 успішних випадків**: один простий тест і сім параметризованих.

```bash
# Лише перший приклад
python -m pytest -q test_image_ops.py

# Граничні сценарії з назвами у звіті
python -m pytest -v test_boundaries.py

# Той самий набір на правильній і трьох дефектних реалізаціях
python demo_defects.py

# Перший тест пропускає обидва відсутні обмеження
python demo_defects.py --suite first

# Після створення власного test_student.py
python demo_defects.py --suite student
```

Експеримент із дефектами працює в тимчасових копіях і не змінює ваші файли. Навмисні `FAILED` у цьому експерименті очікувані: вони показують, який дефект помітили перевірки. Звичайний початковий запуск `pytest` має бути повністю успішним.

## Контракт

- `pixel` — звичайне ціле число Python від 0 до 255 включно.
- `delta` — ціла зміна яскравості.
- `brighten(pixel, delta)` повертає суму з обмеженням знизу 0 і зверху 255.
- Поведінку для аргументів поза цими передумовами не задано; перевірки винятків потребували б додаткових вимог.
